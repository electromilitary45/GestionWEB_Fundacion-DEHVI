<div class="markdown-heading" dir="auto">
  <h2>Nuestro TCU</h2>
  <a id="nuestro-tcu" class="anchor" aria-label="Permalink: Nuestro TCU" href="#nuestro-tcu"></a>
</div>

<p dir="auto">
Nuestro proyecto consiste en el desarrollo e implementación de una Aplicacion de Gestión y Organización automatizada de archivos mediante control de versiones, a través de un sistema web basado en .NET Framework. Surge como respuesta a los desafíos significativos que enfrenta la fundación DEHVI en su gestión documental interna, marcada por la dependencia de procesos manuales con el uso de archivos de Excel y la plataforma SharePoint. Esta dependencia de métodos obsoletos e ineficientes dificulta la fluidez de las operaciones internas y aumenta el riesgo de errores en la documentación.
</p>

<div class="markdown-heading" dir="auto">
  <h3>Objetivos</h3>
  <a id="objetivos" class="anchor" aria-label="Permalink: Objetivos" href="#objetivos"></a>
</div>
<p>
Nuestro objetivo principal es desarrollar una aplicación web que atienda de manera precisa las necesidades de cada sector de la Fundación DEHVI, garantizando una gestión documental eficiente, un control preciso de versiones y una interfaz de usuario intuitiva para mejorar la accesibilidad y usabilidad en toda la organización. Para lograr esto, nos enfocaremos en interpretar y documentar las necesidades específicas de cada sector, diseñar un sistema de control de versiones que permita el seguimiento de actualizaciones y modificaciones, e implementar una interfaz de usuario intuitiva y fácil de usar en el aplicativo web.
</p>
